# Otilia Manasoiu — shooting-star academic website

A lightweight multi-page static website with an animated canvas starfield and shooting stars.

## Preview locally

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish on GitHub Pages

1. Create a public repository named `OtiliaIrina.github.io`.
2. Upload all files in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main`, and use `/ (root)`.

## Personalise

- Add a public email or social links in `cv.html`.
- Replace the research wording as projects evolve.
- Add a PDF CV and link it from `cv.html`.
- Add publication links in `publications.html` once ready.
